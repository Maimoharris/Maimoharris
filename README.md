## 📚 Security Philosophy

> **Automated tools find patterns.
> Manual testing finds assumptions.
> Exploitation proves impact.**

I believe effective security testing goes beyond running scanners.

The goal is to understand how a system actually works, identify where its security assumptions break, demonstrate meaningful impact, and provide developers with information they can use to fix the underlying problem.
