- How the OS handles a process
- How memory is allocated and managed
- How applications communicate
- How protocols move data
- How authentication & authorization are implemented
- How APIs expose business logic
- How vulnerabilities cross trust boundaries
- How software can be engineered to resist those failures

That systems-level understanding is what I bring into offensive security.

## 🔬 Security Research

My security work revolves around understanding the complete attack surface rather than treating vulnerabilities as isolated bugs.

<div align="center">

`Recon` → `Attack Surface Mapping` → `Architecture Understanding` → `Vulnerability Discovery` → `Exploit Validation` → `Impact Analysis` → `Automation` → `Remediation`

</div>

Areas I've worked across: **API · Web · Mobile · Network · Active Directory · IoT · Cloud · Systems**

My approach combines automated tooling with manual analysis — the most interesting vulnerabilities are often found in the assumptions between components.
